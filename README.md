# ⚡ DealHunter AI - Nền Tảng Săn Deal & Tiếp Thị Liên Kết Thông Minh

Nền tảng web hiện đại giúp xây dựng nguồn **thu nhập thụ động (Passive Income)** thông qua mô hình Tiếp thị liên kết (Affiliate Marketing) và Đánh giá sản phẩm chuẩn SEO từ các sàn TMĐT lớn: **Shopee, Lazada, TikTok Shop, Tiki**.

---

## 🌟 Tính Năng Nổi Bật

- 🎨 **Giao diện đẳng cấp & hiện đại**: Thiết kế phong cách Dark/Light mode, Glassmorphism, hiệu ứng chuyển động mượt mà, typography tối ưu trải nghiệm người dùng.
- ⏱️ **Flash Sale Countdown**: Bộ đếm ngược thời gian thực kích thích người mua bấm chốt deal nhanh chóng.
- 🏷️ **Tự động gắn mã Affiliate Tracking**: Tự động chèn mã của bạn (Shopee, Lazada, TikTok, Tiki) vào mọi link điều hướng.
- 🎟️ **Copy Voucher 1 chạm**: Người dùng sao chép mã giảm giá tức thì kèm thông báo Toast notification.
- 🧮 **Máy tính tiết kiệm thông minh**: Công cụ tính trực quan số tiền tiết kiệm được từ mã giảm giá.
- 📝 **Bài viết đánh giá chuẩn SEO**: Tích hợp cấu trúc dữ liệu Schema.org JSON-LD (Product, Review, Offer, WebSite) giúp Google dễ dàng đưa bài viết lên top tìm kiếm.
- ⚙️ **Trang Quản trị Admin chuyên nghiệp** (`admin.html`):
  - Cấu hình mã Affiliate ID của bạn chỉ với 1 cú click.
  - Thống kê lượt click, ước tính GMV và hoa hồng thụ động thu về.
  - Thêm / Sửa / Xóa deal nhanh gọn.
  - Trình AI tạo bài viết SEO review tự động.
  - Xuất / Nhập và sao lưu dữ liệu JSON an toàn.
- 🐍 **Công cụ Python tự động hóa** (`tools/deal_generator.py`):
  - Tạo nội dung chia sẻ mạng xã hội (Facebook, Telegram, Zalo) tự động kèm link tracking.
  - Tạo bài viết review Markdown chuẩn SEO.

## 🚀 Hướng Dẫn Sử Dụng Nhanh

### 1. Xem Website Trực Tiếp Trên Máy Tính
Bạn chỉ cần mở trực tiếp file `index.html` bằng trình duyệt (Chrome, Edge, Cốc Cốc, Firefox) hoặc khởi chạy máy chủ thử nghiệm:
```powershell
python -m http.server 8080
```
Sau đó truy cập: `http://localhost:8080`
